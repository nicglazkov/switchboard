# Keyboard shortcuts

<p class="sb-meta">Last validated: Nov 22, 2026</p>

This page lists every keyboard shortcut in the Switchboard desktop app. Where one column is given, read
++ctrl++ on Windows and Linux for ++cmd++ on a Mac.

!!! note ""
    Inside a terminal on Windows and Linux, plain ++ctrl+w++, ++ctrl+t++, ++ctrl+o++, ++ctrl+b++, ++ctrl+k++,
    ++ctrl+n++ and ++ctrl+q++ belong to the program in the terminal. Add ++shift++ to reach Switchboard, for
    example ++ctrl+shift+k++ for the command palette. On a Mac, ++cmd++ always goes to Switchboard.

## Everywhere

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++cmd+k++ | ++ctrl+k++ | Open the command palette: commands, chats and a new terminal for each shell |
| ++cmd+n++ | ++ctrl+n++ | Start a new chat |
| ++cmd+t++ | ++ctrl+t++ | Open a new terminal with your default shell |
| ++cmd+o++ | ++ctrl+o++ | Find a chat and open it in a terminal |
| ++cmd+b++ | ++ctrl+b++ | Open History |
| ++cmd+1++ | ++ctrl+1++ | Show the board |
| ++cmd+2++ to ++cmd+8++ | ++ctrl+2++ to ++ctrl+8++ | Show a terminal tab, in the order of the tab row. Tabs in a folded group are skipped |
| ++cmd+9++ | ++ctrl+9++ | Show the last tab in the row |
| ++cmd+w++ | ++ctrl+w++ | Close the thing on top: a sheet, a floating terminal, a tab, then the window. With terminal tabs open, the window closes on a second press |
| ++cmd+shift+l++ | ++ctrl+shift+l++ | Switch between light and dark |
| ++cmd+comma++ | ++ctrl+comma++ | Open Settings |
| ++cmd+q++ | ++ctrl+q++ | Quit. Switchboard asks first while one of your own shells is running a program |
| ++esc++ | ++esc++ | Close what is on top, one layer at a time |

## On the board

The letter keys work when nothing is open over the board and you aren't typing in a field. For more
information, refer to [The board](board.md).

| Key | What it does |
|---|---|
| ++j++ or ++down++ | Select the next chat |
| ++k++ or ++up++ | Select the previous chat |
| ++l++ or ++right++ | Move to the next column that has a chat, in the same row |
| ++h++ or ++left++ | Move to the previous column that has a chat, in the same row |
| ++enter++ | Open the chat in a terminal tab, resuming it first if it was stopped |
| ++shift+enter++ | Open the chat's terminal in a window |
| ++alt+enter++ | Open the chat's terminal as a floating sheet |
| ++f++ | Start fresh |
| ++r++ | Resume |
| ++c++ | Continue on another computer |
| ++n++ | Start a new chat |
| ++tab++, ++shift+tab++ | Move between buttons |

## In the new chat sheet

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++cmd+enter++ | ++ctrl+enter++ | Start the chat |
| ++tab++ | ++tab++ | Move between the message and the new folder's name |

## In a terminal

++enter++, ++esc++ and ++tab++ go to the program in the terminal. Selecting text copies it. A right-click
copies the selection, or pastes when nothing is selected. For more information, refer to
[Terminals](terminals.md).

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++cmd+c++ | ++ctrl+c++ with text selected, ++ctrl+shift+c++ or ++ctrl+insert++ | Copy |
| ++cmd+v++ | ++ctrl+v++, ++ctrl+shift+v++ or ++shift+insert++ | Paste |
| ++ctrl+c++ with text selected | The same | Copy. With nothing selected, ++ctrl+c++ goes to the program |
| ++shift+page-up++, ++shift+page-down++ | The same | Scroll one page |
| ++cmd+up++, ++cmd+down++ | ++ctrl+home++, ++ctrl+end++ | Scroll to the top or the bottom |
| ++cmd+left++, ++cmd+right++ | ++home++, ++end++ | Move to the start or the end of the line |
| ++option+left++, ++option+right++ | ++ctrl+left++, ++ctrl+right++ | Move back or forward one word |
| ++option+backspace++ | ++ctrl+backspace++ | Delete a word |
| ++cmd+backspace++ | None | Delete to the start of the line |
| ++cmd+plus++, ++cmd+minus++, ++cmd+0++ | ++ctrl+plus++, ++ctrl+minus++, ++ctrl+0++ | Make the text bigger, smaller or its usual size |
| ++cmd+shift+r++ | ++ctrl+shift+r++ | Redraw the terminal |

## In the command palette

| Key | What it does |
|---|---|
| ++up++, ++down++ | Move through the list |
| ++ctrl+p++, ++ctrl+n++ | Move up or down, as an alternative to the arrows |
| ++enter++ | Run the selected row |

With nothing typed, the first row is a new terminal with your default shell, so ++cmd+k++ followed by
++enter++ opens one.

## In Files

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++up++, ++down++ | The same | Move through the list |
| ++enter++ or ++cmd+down++ | ++enter++ or ++ctrl+down++ | Open the selected item |
| ++right++ | The same | Go into the folder |
| ++left++, ++backspace++ or ++cmd+up++ | ++left++, ++backspace++ or ++ctrl+up++ | Go up to the parent folder |
| ++cmd+bracket-left++, ++cmd+bracket-right++ | ++ctrl+bracket-left++, ++ctrl+bracket-right++ | Go back or forward through the folders you visited |
| ++space++ | The same | Quick look |
