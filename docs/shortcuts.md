# Keyboard shortcuts

Switchboard is built to run from the keyboard. On Windows and Linux, read ++ctrl++ where a Mac uses ++cmd++.

!!! tip "Inside a terminal on Windows and Linux"
    There, plain ++ctrl+w++, ++ctrl+t++, ++ctrl+o++, ++ctrl+b++, ++ctrl+k++, ++ctrl+n++ and ++ctrl+q++ belong to the program in
    the terminal. Add ++shift++ for Switchboard's: ++ctrl+shift+k++ opens the command palette, and so on. The
    menus show these forms. On a Mac, ++cmd++ always goes to Switchboard.

## Everywhere

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++cmd+k++ | ++ctrl+k++ | Command palette: commands, chats, and a new terminal per shell |
| ++cmd+n++ | ++ctrl+n++ | New chat |
| ++cmd+t++ | ++ctrl+t++ | New terminal, with your default shell |
| ++cmd+o++ | ++ctrl+o++ | Find a chat and open it in a terminal |
| ++cmd+b++ | ++ctrl+b++ | History |
| ++cmd+1++ | ++ctrl+1++ | The board |
| ++cmd+2++ to ++cmd+8++ | ++ctrl+2++ to ++ctrl+8++ | Terminal tabs, in order |
| ++cmd+9++ | ++ctrl+9++ | The last tab |
| ++cmd+w++ | ++ctrl+w++ | Close the top thing: a sheet, a floating terminal, a tab, then the window |
| ++cmd+shift+l++ | ++ctrl+shift+l++ | Switch light and dark |
| ++cmd+comma++ | ++ctrl+comma++ | Settings |
| ++cmd+q++ | ++ctrl+q++ | Quit |
| ++esc++ | ++esc++ | Close what's on top, one layer at a time |

## On the board

These work when you aren't typing in a field.

| Key | What it does |
|---|---|
| ++j++ or ++down++ | Next chat |
| ++k++ or ++up++ | Previous chat |
| ++l++ or ++right++ | Next column |
| ++h++ or ++left++ | Previous column |
| ++enter++ | Open the chat: in a tab, resuming it if it was stopped |
| ++shift+enter++ | Open its terminal in a window |
| ++alt+enter++ | Open its terminal as a floating sheet |
| ++f++ | Start fresh |
| ++r++ | Resume |
| ++c++ | Continue on another computer |
| ++n++ | New chat |
| ++tab++, ++shift+tab++ | Move between buttons |

## In a terminal

++enter++, ++esc++ and ++tab++ go to the program.

| Mac | Windows and Linux | What it does |
|---|---|---|
| ++cmd+c++, ++cmd+v++ | ++ctrl+shift+c++, ++ctrl+shift+v++ or ++shift+insert++ | Copy, paste |
| ++shift+page-up++, ++shift+page-down++ | the same | Scroll |
| ++cmd+up++, ++cmd+down++ | ++ctrl+home++, ++ctrl+end++ | Scroll to the top, the bottom |
| ++cmd+left++, ++cmd+right++ | ++home++, ++end++ | Start, end of the line |
| ++option+left++, ++option+right++ | ++ctrl+left++, ++ctrl+right++ | Back, forward a word |
| ++option+backspace++ | ++ctrl+backspace++ | Delete a word |
| ++cmd+backspace++ | | Delete to the start of the line |
| ++cmd+plus++, ++cmd+minus++, ++cmd+0++ | ++ctrl+plus++, ++ctrl+minus++, ++ctrl+0++ | Bigger, smaller, actual size text |
| ++cmd+shift+r++ | ++ctrl+shift+r++ | Redraw the terminal |

## In the command palette

| Key | What it does |
|---|---|
| ++up++, ++down++ (or ++ctrl+p++, ++ctrl+n++) | Move |
| ++enter++ | Run |

++cmd+k++ then ++enter++ opens a new terminal with your default shell, since **New terminal** rows come first.

## In Files

| Key | What it does |
|---|---|
| ++up++, ++down++ | Move |
| ++enter++ | Open |
| ++right++ | Into the folder |
| ++left++, ++backspace++ or ++cmd+up++ | Up to the parent folder |
| ++cmd+down++ | Open |
| ++space++ | Quick look |
