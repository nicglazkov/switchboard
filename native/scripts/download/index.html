The desktop board for your Claude Code sessions on every machine you link. Paste one line on the computer you are using and it installs and opens.

macOS

This computer

One app for Apple silicon and Intel Macs. Paste into Terminal.

▸ curl -fsSL {{BASE}}/{{MAC_FILE}} -o /tmp/sb.zip && rm -rf ~/Applications/Switchboard.app && ditto -x -k /tmp/sb.zip ~/Applications && open ~/Applications/Switchboard.app

Installs to ~/Applications and needs nothing else. Files fetched with curl are not quarantined, so macOS opens it without the Gatekeeper prompt.

Windows

This computer

64-bit Windows 10 or 11. Paste into PowerShell; no admin needed.

▸ $d="$env:LOCALAPPDATA\Programs\Switchboard"; $ProgressPreference='SilentlyContinue'; Stop-Process -Name Switchboard -ErrorAction Ignore; Invoke-WebRequest {{BASE}}/{{WIN_FILE}} -OutFile "$env:TEMP\sb.zip" -UseBasicParsing; Expand-Archive "$env:TEMP\sb.zip" $d -Force; $s=(New-Object -ComObject WScript.Shell).CreateShortcut("$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Switchboard.lnk"); $s.TargetPath="$d\Switchboard.exe"; $s.Save(); Start-Process "$d\Switchboard.exe"

Installs for your account in %LOCALAPPDATA%\Programs\Switchboard, adds Switchboard to the Start menu and opens it. Run it again to update.

▸ mkdir -p ~/.local/bin && curl -fsSL {{BASE}}/{{LINUX_FILE}} -o ~/.local/bin/sb.new && chmod +x ~/.local/bin/sb.new && mv -f ~/.local/bin/sb.new ~/.local/bin/switchboard && setsid -f ~/.local/bin/switchboard >/dev/null 2>&1

One file, saved as ~/.local/bin/switchboard. Run it again to update.
